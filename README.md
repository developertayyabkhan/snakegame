# Snake Game

A small browser-based snake game built with HTML, CSS, and JavaScript.

## Features
- Difficulty selection
- Pause and restart controls
- Sound toggle
- Local leaderboard tracking
- Responsive game layout

## Run locally
1. Open `index.html` in a browser.
2. Or serve the folder with a local static server, such as:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`.

## Files
- `index.html` — game structure and UI
- `styles.css` — game styling and layout
- `script.js` — game logic and interactions

## Repository status
This repository contains the complete snake game source code and can be opened directly in a browser.
